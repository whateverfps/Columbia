# Columbia Enterprise AI — Working Concept

A single static, GitHub Pages-ready experience created for a working conversation.

## Start
Open `index.html`.

## Experience flow
- `index.html` — cinematic personal introduction by Paul Thibodeau
- `enterprise.html` — company Enterprise AI Suite
- `pm-super.html` — PM + Superintendent personal AI suite
- `finance.html` — Finance personal AI suite
- `studio.html` — broader AI Studio / program concept
- `demo-flow.html` — private presenter flow

## Local preview
```bash
python3 -m http.server 8080
```
Then open http://localhost:8080

## GitHub Pages
Push the contents of this folder to the repository root and enable Pages from `main` / root.
