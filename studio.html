PROGRAM OPERATING MODEL

First 90 Days: Learn → Prove → Establish

An intentionally light starting structure. The organization teaches the program what it needs.

01
DAYS 1–30

Learn the operation

Listen, observe, map systems and data, understand current AI use, identify champions and establish risk boundaries.

02
DAYS 31–60

Run focused pilots

Select a few high-value, low-regret problems. Establish baselines, prototype quickly and put solutions in users' hands.

03
DAYS 61–90

Establish the program

Scale winners, stop weak experiments, formalize intake and governance, build training and publish the next roadmap.
